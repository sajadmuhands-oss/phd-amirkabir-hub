الوحدة 02

ما هو MATLAB وواجهة العمل؟

MATLAB بيئة حسابية عالية المستوى للحساب العددي، التصور، ومحاكاة الأنظمة — مع واجهة عمل متكاملة.

Command Windowتنفيذ الأوامر فورياً وعرض النتائج.
Workspaceعرض المتغيرات والقيم المخزّنة في الذاكرة.
Editorكتابة السكربتات والدوال مع تصحيح الأخطاء.
Current Folderإدارة المسار والملفات النشطة للمشروع.

نواتج التعلّم

  • تمييز أدوار نوافذ MATLAB الأربع الأساسية.
  • تشغيل أمر بسيط ومراقبة ظهور المتغير في Workspace.
الوحدة 03

المتغيرات والمصفوفات

كل شيء في MATLAB مصفوفة. إتقان إنشاء المتجهات والمصفوفات هو أساس السرعة والدقة.

إنشاء أساسي
% متجه صف ومتجه عمود
a = [1 2 3 4];
b = [1; 2; 3];
A = [1 2 3; 4 5 6];
Z = zeros(3); I = eye(3);
123456789

مفاهيم أساسية

  • size / length لمعرفة الأبعاد.
  • الفهرسة بـ A(i,j) والشريحة A(:,2).
  • الدمج الأفقي [A B] والعمودي [A; B].

نواتج التعلّم

  • إنشاء متجهات ومصفوفات بطرق متعددة.
  • قراءة وفهرسة عناصر المصفوفة بثقة.
الوحدة 04

العمليات الحسابية والمنطقية

الفرق الجوهري: ضرب المصفوفات * مقابل العمليات عنصرًا بعنصر .* ./ .^

Matrix ops

عمليات مصفوفية

C = A * B;
D = A \ b;
E = A.';

تتطلّب توافق الأبعاد وفق قواعد الجبر الخطي.

Element-wise

عنصرًا بعنصر

C = A .* B;
D = A ./ B;
E = A .^ 2;

مثالية لمعالجة الإشارات والصور والنقاط البيانية.

نواتج التعلّم

  • اختيار العملية الصحيحة حسب الهدف الحسابي.
  • استخدام المقارنات المنطقية لتصفية البيانات.
الوحدة 05

البرمجة: الشروط والحلقات

حوّل الحسابات اليدوية إلى منطق قابل للتكرار مع if و for و while.

for k = 1:10
    if mod(k,2)==0
        disp(['even ' num2str(k)])
    else
        disp(['odd  ' num2str(k)])
    end
end
ابدأ→ شرط؟→ نفّذ كتلة→ تكرار / خروج

نصيحة أداء

فضّل العمليات المتجهية (vectorization) على الحلقات الثقيلة كلما أمكن.

نواتج التعلّم

  • كتابة شروط متداخلة وحلقات آمنة.
  • معرفة متى تستبدل الحلقة بعملية متجهية.
الوحدة 06

الدوال والسكربتات

السكربت ينفّذ أوامر في Workspace العام؛ الدالة تعزل المدخلات والمخرجات وتعيد الاستخدام.

function file
function [m,s] = stats_basic(x)
    m = mean(x); s = std(x);
end
script
data = rand(1,200);
[mu,sig] = stats_basic(data);

نواتج التعلّم

  • التفريق بين script و function واختيار الأنسب.
  • كتابة دالة بمخرجات متعددة وتوثيقها.
الوحدة 07

الرسوم البيانية والتصور

من plot إلى الرسوم ثلاثية الأبعاد — التصور الجيد يختصر صفحات من النتائج الرقمية.

x = 0:0.05:2*pi;
y1 = sin(x); y2 = cos(x);
figure; hold on
plot(x,y1,'LineWidth',2)
plot(x,y2,'--')
grid on; legend('sin','cos')

الوحدة 09

Simulink وأدوات النمذجة

نمذجة الأنظمة بالسحب والإفلات: إشارة → كتلة ديناميكية → راسم → تحليل.

Source→ Plant / Controller→ Sink / Scope

متى تستخدم Simulink؟

  • أنظمة التحكم والديناميكا المستمرة/المتقطعة.
  • محاكاة متعددة المجالات.
  • Model-Based Design وتوليد الكود.

نواتج التعلّم

  • وصف مسار إشارة بسيط في Simulink.
  • ربط نمذجة الكتل بمفاهيم MATLAB الحسابية.
الوحدة 10

مشاريع احترافية وأفضل الممارسات

اختتم المسار بمشروع متكامل وعادات عمل تليق ببحث الدكتوراه.

مشروع 1

تحليل إشارة: استيراد → تنظيف → رسم → مؤشرات.

مشروع 2

حل نظام معادلات ومحاكاة استجابة خطوة.

مشروع 3

نموذج Simulink لمتحكم مع مقارنة سيناريوهات.

أفضل الممارسات

  • أسماء ملفات ودوال واضحة، وتعليقات هادفة.
  • فصل البيانات / الكود / النتائج في مجلدات منظمة.
  • تجنّب clear all العشوائي؛ استخدم نطاقاً محلياً عبر الدوال.
  • ثبّت البذور العشوائية لإعادة الإنتاج العلمي.

نواتج التعلّم الختامية

  • امتلاك مسار عمل من الفكرة إلى نتيجة قابلة للعرض.
  • تطبيق عادات تنظيم الكود المناسبة للبحث الأكاديمي.
