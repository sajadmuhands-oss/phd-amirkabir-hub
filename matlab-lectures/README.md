# محاضرات ماتلاب — من الصفر إلى الاحتراف

ملف Word قابل للتعديل مع رسومات وإنفوجرافيك، **بدون أي ربط بمنصة الويب**.

## الملف الجاهز

- `محاضرات_ماتلاب_من_الصفر_إلى_الاحتراف.docx` — افتحه في Microsoft Word وعدّل بحرية.
- `assets/` — الصور المستخدمة داخل المستند (يمكن استبدال أي صورة ثم إعادة إدراجها في Word).

## محتوى المحاضرات

0. خارطة الطريق  
1. ما هو MATLAB وواجهة العمل  
2. المتغيرات والمصفوفات  
3. العمليات الحسابية والمنطقية  
4. البرمجة: الشروط والحلقات  
5. السكربتات والدوال  
6. الرسوم البيانية والتصور  
7. تحليل البيانات والملفات  
8. مقدمة Simulink  
9. أدوات الاحتراف  
10. مشروع ختامي ومسار الاحتراف  

## إعادة توليد المستند (اختياري)

```bash
pip install python-docx pillow
python3 generate_matlab_lectures_docx.py
```
